# Sonic X Bedrock

Sonic X Bedrock is a Minecraft plugin that adds a Sonic-themed experience to your Bedrock server. It includes a Mobius dimension, a revive totem, and the ability to transform into a Sonic character or Metal Sonic. The plugin is designed to enhance the Minecraft experience with elements from the Sonic series.

## Install

1. Download the plugin from the GitHub repository.
2. Place the plugin file in the `plugins` folder of your Bedrock server.
3. Restart your server to load the plugin.

## Use

1. **Mobius Dimension**: To enter the Mobius dimension, place four oak logs in a 2x2 area and jump. You will be teleported to the Mobius dimension.
2. **Revive Totem**: Craft a revive totem using the recipe: four oak logs in an L shape and two dirt blocks next to it. If you die with the revive totem in your inventory, you will be revived as a Sonic character.
3. **Eggman's Base**: Find Eggman's base and die there without a revive totem. You will be transformed into Metal Sonic.
4. **Sonic Abilities**: As a Sonic character, you will gain increased speed while sprinting and increased jump height when you right-click.
